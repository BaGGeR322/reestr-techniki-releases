# Реестр техники — установщик

Здесь лежат только готовые версии программы «Реестр техники» для Windows и файлы для её автообновления.

## Как установить

1. Откройте **[последний релиз](https://github.com/BaGGeR322/reestr-techniki-releases/releases/latest)**.
2. Скачайте `ReestrTehniki-win-Setup.exe` и запустите.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**.
   Программа не подписана сертификатом, это нужно один раз.

Без установки: скачайте `ReestrTehniki-win-Portable.zip`, распакуйте и запускайте `ReestrTehniki.exe`.

Нужна Windows 10 или 11 (64-бит). Интернет нужен только для обновлений.

## Обновления

Программа сама проверяет этот репозиторий при запуске и предлагает обновиться.
Данные лежат в `Документы\Реестр техники` и при обновлении не теряются.
